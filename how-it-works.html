How DesignFlow Works

A practical, local-first planning tool that produces clear outputs for humans and AI builders — styled in the RavenPower visual system.

The Problem It Solves

Most website projects start with vague requirements. That leads to scope creep, mismatched expectations, and expensive revisions. DesignFlow forces structured thinking upfront.

The 6-Step Flow

  1. Project Overview — Business name, industry/niche, and website goals.
  2. Target Audience — Who you're building for, pain points, and desired outcomes.
  3. Messaging & Content Strategy — Value proposition, homepage headline, CTA, key message, and tone.
  4. Key Features & Site Structure — Ordered page list (sitemap order), must-have features, and technical requirements.
  5. Design Direction & Branding — Primary/accent colors and overall visual vibe (defaults to RavenPower Dark).
  6. Review & Export — Live color preview, summary, JSON download, and Markdown design brief. Drafts autosave in your browser; import a previous JSON export to continue editing.

RavenPower Brand Language

DesignFlow ships with RavenPower's commerce visual system: cool near-black canvas, Space Grotesk display type, Inter body, and a restrained green accent (#56d08a). Accent is used for focus, progress, and primary actions — not as a painted fill.

Perfect Companion for RavenPower builds

The structured JSON output is ideal input for RavenPower / RavenClaude agents, especially:

  • Web Strategist
  • UI/UX Designer
  • Information Architect
  • Frontend Engineer
  • Integration Specialist

Hand the exported JSON to the team (or to RavenClaude) and get a production-ready website with far less back-and-forth.

Pro Tip

After exporting the JSON, drop it into a new RavenClaude session along with any reference sites. The agents will use it as structured context to generate wireframes, copy, component specs, or implementation plans.

Privacy note: your answers stay in the browser (localStorage draft + local export). Styling libraries may still load from CDNs when you open the HTML files.
